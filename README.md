## 📋 Enunciado da Atividade

1. Crie um projeto e utilize os arquivos `index.html` e `style.css`, incluindo o CSS de forma Externa ao HTML, através da tag `<link>`.
2. Adicione 20 elementos e atribua valores em todas as propriedades de **Content**, **Padding**, **Border** e **Margin**.
3. Em seguida, adicione 20 propriedades de **Flexbox** para manipular os elementos e organizá-los de forma responsiva.

---

## 🚀 Como Executar

Abra o arquivo `index.html` em qualquer navegador (Google Chrome, Microsoft Edge, Firefox):
* **Zero Setup:** Não requer instalação de dependências ou servidores locais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Marcação estruturada com 20 elementos identificados (`elem-01` a `elem-20`).
- **CSS3 Externo (`style.css`):** Vinculado via tag `<link>`, com auditoria das 4 camadas do Box Model e mais de 20 propriedades Flexbox aplicadas responsivamente.
